# Paid Memberships Pro - Command Palette

![License](https://img.shields.io/badge/license-GPL--3.0%2B-red.svg?style=flat-square)

### Welcome to the Paid Memberships Pro - Command Palette GitHub Repository
Adds Paid Memberships Pro commands to the WordPress command palette on WordPress 7.0+.

This plugin exposes PMPro admin actions and PMPro quick-search results inside the WordPress command palette without duplicating core menu navigation commands that WordPress already provides.

## Requirements

1. WordPress 7.0 or newer.
2. Paid Memberships Pro must be installed and active.

## Installation

1. Clone or download this repository into `wp-content/plugins/pmpro-command-palette`.
2. Activate Paid Memberships Pro.
3. Activate Paid Memberships Pro - Command Palette.

## Included Commands

1. Add New Member.
2. Create Membership Level.
3. Create Discount Code.
4. Open Setup Wizard.
5. Open Add Ons.
6. Dynamic PMPro quick-search results for users, subscriptions, orders, reports, levels, discount codes, settings, and documentation.
